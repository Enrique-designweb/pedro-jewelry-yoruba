# Pedro Jewelry Yoruba - E-commerce Website

## 📝 Project Overview

A fully responsive e-commerce website developed for a jewelry brand. The project focused on delivering a seamless user experience, high performance, and modern design.

## 🛠️ Tech Stack

- **Framework:** Next.js, React
- **Styling:** CSS / Tailwind CSS
- **Hosting:** Netlify
- **Analytics:** Google Analytics, Google Tag Manager
- **Performance:** Priority Hints, PWA

## ✨ Key Features

- Responsive and modern UI.
- Product catalog and Cart Functionality.
- Optimized for SEO and performance.
- Integration with Google Analytics for tracking.
